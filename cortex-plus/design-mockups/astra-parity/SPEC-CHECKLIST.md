# Astra parity — karşılaştırma checklist

Her ekran için Astra TR ile yan yana bak. **Evet / Kısmen / Hayır** not düş.

## Global

- [ ] Primary CTA rengi **#f4ae0b**, koyu zemin üstünde okunaklı
- [ ] Figtree benzeri sans, başlık–gövde hiyerarşisi net
- [ ] Kopya **sen** dilinde, eğitim odaklı
- [ ] Premium yönlendirme görünür ama baskın değil (Astra ritmi)

## 1. Marketing

- [ ] Üst nav: logo, ana linkler, belirgin **Ücretsiz dene / Başla**
- [ ] Hero: video + scrim, tek odak CTA
- [ ] Footer: legal + yardım linkleri (app path’lerde footer yok)
- [ ] Sosyal kanıt / plan alanı Astra yoğunluğuna yakın

## 2. Onboarding

- [ ] İlerleme çubuğu üstte
- [ ] Rol kartları: emoji + başlık + kısa açıklama, tek sütun mobil
- [ ] Devam CTA altın, geri oku sol üst

## 3. Login

- [ ] **Google ile devam et** en üstte, tam genişlik
- [ ] E-posta/şifre ikincil (ayraç “veya”)
- [ ] Kayıt linki görünür

## 4. Sor (boş chat)

- [ ] Üst: streak / kredi / **Satın al ✦**
- [ ] Orta: selamlama + boş alan (hub grid yok veya minimal)
- [ ] Alt: composer + **3 tab** (Sor · Sınavlar · Uygulamalar) + menü karesi
- [ ] Menü: gruplu kısayollar (onay sonrası detay)

## 5. Pay

- [ ] Plus değer önermesi + fiyat kartı
- [ ] Tek ana satın al CTA
- [ ] Ücretsiz plan geri dönüş linki
